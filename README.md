# Budgetplaner PWA – vollständige Ersatzversion

## Dateien für GitHub Pages

Lade den gesamten Inhalt dieses Ordners in dein bestehendes Repository:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- den vollständigen Ordner `icons`

Die bisherige `index.html` wird vollständig ersetzt. Bestehende Daten aus einer älteren App-Version können wegen einer anderen lokalen Datenstruktur nicht automatisch übernommen werden. Erstelle deshalb vor dem Austausch, falls möglich, eine Sicherung der alten Daten.

## Installation auf dem iPhone

1. Öffne nach dem Hochladen die GitHub-Pages-Adresse in Safari.
2. Tippe unten auf **Teilen**.
3. Wähle **Zum Home-Bildschirm**.
4. Aktiviere **Als Web-App öffnen**, falls diese Option angezeigt wird.
5. Tippe auf **Hinzufügen**.

## Enthaltene Funktionen

- aktueller Monat wird automatisch gewählt
- Cockpit mit verfügbarem Betrag und vier Kennzahlen
- Fixeinnahmen global, Zusatzeinnahmen pro Monat
- monatliche und jährliche Fixkosten global
- jährliche Rücklage wird automatisch durch zwölf geteilt
- variable Ausgaben mit aktuellem Datum und zuletzt verwendeter Kategorie
- Kategorie-Budgets und Warnungen ab 80 Prozent
- Fälligkeit und Bezahlt-Status für Jahresrechnungen
- 6-Monats-Verlauf und Jahresprognose
- Sparziele
- Suche und Kategorienfilter
- Bearbeiten, Löschen und Duplizieren
- JSON-Sicherung und Wiederherstellung
- CSV-Export für Excel
- Druckansicht
- optionaler lokaler PIN-Schutz
- Offline-Unterstützung nach dem ersten erfolgreichen Laden

Alle Budgetdaten werden nur lokal im Browser auf dem Gerät gespeichert.
